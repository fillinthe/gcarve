Single-line (stroke) fonts for engraving: futural (Single Line Sans), scripts (Single Line Script),
cursive (Single Line Cursive). Data files from github.com/kamalmostafa/hershey-fonts
(hershey-fonts/*.jhf; the GPL in that repository covers its C library, not these files), unchanged.

The Hershey Fonts were originally created by Dr. A. V. Hershey while working at the U. S. National Bureau of
Standards. The format of the Font data in this distribution was originally created by James Hurt, Cognition, Inc.,
900 Technology Park Drive, Billerica, MA 01821. Usage terms: hershey.txt.
