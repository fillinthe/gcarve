**What's new in 0.1.31**
- GCarve Control: Start Program no longer refuses a job on machines whose machine coordinates count down from home (stock GRBL after homing, for example FoxAlien). The travel check now takes both ways of counting.
- GCarve Control: Park goes to the back-left corner on those machines too.

Free to use, no account needed. Downloads: macOS (Apple silicon and Intel, signed and notarized), Windows 10/11 and 7/8 (64 and 32-bit), Linux x86-64 and ARM64. Checksums are in SHA256SUMS.txt. The Windows files are not code-signed yet (see the README for the first start).
